# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities privately through GitHub Security Advisories for this repository. Do not open a public issue for a security problem.

Please include the affected version, platform, and steps to reproduce. We will acknowledge the report and coordinate a fix and disclosure with you.

## Verifying downloads

Release artifacts are published by Forion. For the current test builds, compare the SHA-256 digest shown on the release page with the file you downloaded. Signed production releases will include a `SHA256SUMS` file.
